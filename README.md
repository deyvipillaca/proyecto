# Sistema de Registro de Habitaciones de Hotel

Proyecto académico de Arquitectura de Software (IS-488), de la Escuela Profesional de Ingeniería de Sistemas de la Universidad Nacional de San Cristóbal de Huamanga.

## Descripción

Sistema informático orientado a gestionar habitaciones, huéspedes y reservas de un hotel. Busca facilitar el control de disponibilidad, los procesos de check-in/check-out y la consulta de información.

## Actores

- Administrador
- Recepcionista
- Huésped

## Funcionalidades principales

- Inicio de sesión.
- Registro y administración de habitaciones.
- Registro de huéspedes.
- Gestión y consulta de reservas.
- Verificación de disponibilidad.
- Check-in y check-out.
- Actualización del estado de habitaciones.
- Reportes básicos.
