# 05. Restricciones

## Sistema de Registro de Habitaciones de Hotel

### Restricciones identificadas en el documento

1. **Acceso controlado:** solo los usuarios autorizados deben poder acceder al sistema.
2. **Protección de datos:** la información de los huéspedes debe contar con mecanismos de seguridad.
3. **Integridad de la información:** la base de datos debe conservar datos íntegros y consistentes.
4. **Copias de seguridad:** deben poder realizarse respaldos periódicos.
5. **Alcance funcional:** el sistema se centra en habitaciones, huéspedes, reservas, check-in, check-out, estados y consultas de reservas.
6. **Usuarios principales:** el sistema está destinado principalmente al administrador y al personal de recepción.

### Aspectos no especificados

El documento fuente no establece tecnología, lenguaje de programación, plataforma de despliegue, presupuesto ni plazos técnicos. Estos aspectos quedan pendientes de definición.
