# 04. Atributos de calidad

## Sistema de Registro de Habitaciones de Hotel

Los siguientes atributos se derivan de los requerimientos no funcionales descritos en el documento del proyecto.

| Atributo | Descripción |
|---|---|
| Usabilidad | El sistema debe ser fácil de utilizar por el administrador y el personal de recepción. |
| Seguridad | La información debe mantenerse protegida y el acceso debe limitarse a usuarios autorizados. |
| Rendimiento | El sistema debe responder rápidamente a las consultas. |
| Integridad | La base de datos debe conservar la integridad de la información registrada. |
| Recuperabilidad | El sistema debe permitir realizar copias de seguridad. |
| Mantenibilidad | La solución debe poder mantenerse y actualizarse para conservar su funcionamiento. |

> La mantenibilidad se expresa como una consideración de diseño; el documento fuente menciona mantenimiento periódico en sus recomendaciones.
