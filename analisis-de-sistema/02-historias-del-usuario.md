# 02. Historias de usuario

## Sistema de Registro de Habitaciones de Hotel

| ID | Historia de usuario |
|---|---|
| HU01 | Como administrador, quiero iniciar sesión, para acceder de forma segura al sistema. |
| HU02 | Como administrador, quiero registrar, modificar y eliminar habitaciones, para mantener actualizada la información del hotel. |
| HU03 | Como recepcionista, quiero registrar los datos de los huéspedes, para conservar su información de manera organizada. |
| HU04 | Como recepcionista, quiero registrar una reserva asociada a un huésped y una habitación, para organizar las estadías. |
| HU05 | Como recepcionista, quiero consultar la disponibilidad de las habitaciones, para seleccionar una habitación adecuada. |
| HU06 | Como recepcionista, quiero registrar el check-in, para dejar constancia del ingreso del huésped y marcar la habitación como ocupada. |
| HU07 | Como recepcionista, quiero registrar el check-out, para dejar constancia de la salida y actualizar el estado de la habitación. |
| HU08 | Como administrador o recepcionista, quiero consultar las reservas, para revisar la información de las estadías. |
| HU09 | Como administrador, quiero generar reportes básicos, para revisar las operaciones del hotel. |
