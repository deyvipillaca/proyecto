# 03. Requisitos funcionales

## Sistema de Registro de Habitaciones de Hotel

| ID | Requisito funcional |
|---|---|
| RF01 | El sistema debe permitir iniciar sesión. |
| RF02 | El sistema debe permitir registrar habitaciones. |
| RF03 | El sistema debe permitir modificar y eliminar habitaciones. |
| RF04 | El sistema debe permitir registrar huéspedes. |
| RF05 | El sistema debe permitir realizar reservas. |
| RF06 | El sistema debe permitir verificar la disponibilidad de habitaciones. |
| RF07 | El sistema debe permitir registrar el check-in de los huéspedes. |
| RF08 | El sistema debe permitir registrar el check-out de los huéspedes. |
| RF09 | El sistema debe permitir actualizar el estado de las habitaciones. |
| RF10 | El sistema debe permitir consultar las reservas. |
| RF11 | El sistema debe permitir generar reportes básicos. |

## Datos principales

- **Huéspedes:** identificador, nombres, apellidos, documento, teléfono, correo y dirección.
- **Habitaciones:** identificador, número, tipo, capacidad, precio y estado.
- **Reservas:** identificador, huésped, habitación, fecha de entrada, fecha de salida y estado.
- **Usuarios:** identificador, nombre de usuario, contraseña y rol.
